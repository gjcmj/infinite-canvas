## 🔴 需修复的回归问题（#21）

**文件：** `web/src/services/cloud-app-sync.ts`

修复过程中引入了重复行，新行的旧比较器覆盖了正确行的新比较器。

### 问题 1：`mergeIndex` 第 216-217 行

```ts
projects: Array.from(mergedProjectMap.values()).sort((a, b) => (a.updatedAt < b.updatedAt ? 1 : a.updatedAt > b.updatedAt ? -1 : 0)),  // ✅ 正确的三路比较
projects: Array.from(mergedProjectMap.values()).sort((a, b) => (b.updatedAt > a.updatedAt ? 1 : -1)),  // ❌ 相等时始终 -1，覆盖上一行
```

第 217 行的 `projects:` 同名属性会**覆盖**第 216 行的结果。

### 问题 2：`mergeProjects` 第 231-232 行

```ts
return Array.from(map.values()).sort((a, b) => (a.updatedAt < b.updatedAt ? 1 : a.updatedAt > b.updatedAt ? -1 : 0));  // ✅ 正确的三路比较
return Array.from(map.values()).sort((a, b) => (b.updatedAt > a.updatedAt ? 1 : -1));  // ❌ 相等时始终 -1，覆盖上一行
```

第 232 行的 `return` 使第 231 行**无法到达**。

### 修复方式

删除第 217 行和第 232 行，保留正确的三路比较实现。
